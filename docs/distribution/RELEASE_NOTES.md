# Alpha Hex 0.2.0 — Clay and first metal

This playtest returns the active game to Unity 6.3 LTS and removes the circular metal requirement. Start without metal, gather clay, fire bricks, run manual bloomery batches and earn the materials for an efficient foundry.

Manual workplace crews, gradual migration, research, permanent watchtower discovery, renewable trees, finite deposits and travelling cargo are carried forward. Larger hexes and a scaling HUD support the village presentation. Save & Exit, backup recovery, a previous-settlement archive and read-only import of old Unity/Godot saves are included.

Install the Windows **Setup.exe** once. Future published playtests can then be checked and downloaded from the game menu, followed by **Save, update & restart**. Keep the full folder together if using the portable ZIP. The old Godot ZIP cannot update itself into this version. Source pushes still need a verified player build and published release before players see an update.

The build is **unsigned**; the updater does not remove Windows publisher or SmartScreen warnings. No engine installation or player account is needed. The installer may install the Microsoft Visual C++ runtime.

The production verifier reaches first metal at 18.2 simulated minutes and an operating foundry at 31.4 minutes using validated commands. These are feasibility checks, not measured human playtime. The target for the next human playtest is 45–60 minutes; weeks-long progression, combat, boats and animals remain future work.

See [verification](https://github.com/Mixers28/hex-builder/blob/main/docs/VERIFICATION.md) for exact checks and limits. Windows releases are gated by native player, installer and update/restart checks; rendered Windows performance and a complete human playthrough still need feedback.
